# Istituto Tecnico – Sito Web HTML & CSS

# DESCRIZIONE

Progetto front-end realizzato durante il corso di formazione Full Stack Web Developer presso Volta Institute.
Il progetto consiste nella realizzazione di una pagina web dedicata a un istituto tecnico, utilizzando HTML per la struttura dei contenuti e CSS per la presentazione grafica.

# TECNOLOGIE UTILIZZATE

- HTML5 – Struttura e organizzazione dei contenuti.
- CSS3 – Stile e impaginazione della pagina web.

# STRUTTURA DEL PROGETTO

- index.html – Pagina HTML principale.
- index.css – Foglio di stile.
- immagini/ – Risorse grafiche utilizzate nel sito.

# COME VISUALIZZARE IL PROGETTO

Scaricare il repository sul proprio computer.
Aprire il file prova067.html con un browser.
Navigare nella pagina web.

# OBBIETTIVO FORMATIVO

Mettere in pratica le conoscenze acquisite durante il corso, approfondendo la struttura delle pagine HTML, l'applicazione degli stili CSS e l'organizzazione dei file di un progetto web.
